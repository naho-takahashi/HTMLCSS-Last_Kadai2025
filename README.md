## 自分で変更したレイアウト(最低三か所は必須)  
- 「ホーム」ページ上部付近に文章コンテナを追加(日常の中で、音楽が聴こえてくる…のコンテナ)  
- `band-section`,`idol-section`,`popmusic-section`,`support-section`id(アンカーリンク)を追加。  
(index.htmlの「ジャンルから探す」で各ジャンルをクリックすると  
「音楽のルーツ」の「〇〇(ジャンル)のはじまり」の紹介画面に自動的に遷移する。  
music-festival-list.htmlの「ジャンルクイックフィルター」でジャンルを選択すると自動的に遷移する)  
- 「アーティスト」ページのアーティスト一覧の9番目のアーティスト欄を削除(8つのみに残した)  
- 「アーティスト」ページのアーティストフィルターを削除(A~Zのコマで並んでいたものを削除した)  
- 「音楽のツール」ページの検索欄を削除  

## 新たに追加したページ(最低2ページ追加必須)  
- 「register.html」という名前の「新規登録ページ」ファイルを追加  
- 「terms-of-service.html」という名前の「利用規約ページ」ファイルを追加  
- 「privacy-policy.html」という名前の「プライバシーポリシーページ」ファイルを追加  
- 「support.html」という名前の「サポート(ヘルプ・お問い合わせ・FAQ)ページ」ファイルを追加  
- これにより全ページ数が10ページ  

### 工夫したところ  
- 自分らしさを表現できるWebサイトを制作したこと。自分の好きなアーティストと音楽ジャンルをまとめる。  
- レトロな感じに作りたかったため、色をブラウンベースに工夫したところ。  
- アンカーリンクを複数用意して、画面遷移の際に関連ページに飛びやすくしたところ。(オリジナル要素)
